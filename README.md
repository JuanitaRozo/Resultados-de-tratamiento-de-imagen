# Resultados-de-tratamiento-de-imagen
## Descripción
Este proyecto consiste en el análisis y procesamiento de imágenes digitales utilizando Python y OpenCV. Se busca identificar problemas relacionados con la calidad de las imágenes y aplicar técnicas de tratamiento para evaluar los resultados obtenidos.

## Objetivos
Analizar imágenes bajo diferentes condiciones.
Identificar posibles problemas visuales.
Aplicar técnicas de procesamiento de imágenes.
Compare los resultados antes y después del tratamiento.
## Herramientas utilizadas
- Python
- OpenCV
- NumPy
- Pandas
- Matplotlib
- Google Colab
## Desarrollo
El proyecto incluye la carga y visualización de imágenes, el análisis de sus características, la aplicación de técnicas de procesamiento y la evaluación de los resultados mediante comparaciones visuales y métricas.

## Ejecución
El código se encuentra en un cuaderno de Google Colab. Para ejecutarlo, se deben cargar las imágenes necesarias y ejecutar las celdas en orden.
